### #33：受管 IGDv2 部署边界

入口：服务页 → 局域网广播 → 可选 IGDv2 网关租约（`pages/IgdLeaseSettings`）。标准版不附网关配置。组织版仅可在签包前将经审核的**单个**网关配置放入 `entry/src/main/resources/rawfile/igd-create-only.json`。字段为 `description`、`control`（同一私网 IPv4、HTTPS 端口的完整 URL）和 `leafSha256`（可信管理渠道取得的 TLS 叶证书 DER 的 64 位小写十六进制 SHA-256）。不是普通路由器的兼容开关；没有审核或无法验证，不应提供配置。没有远程导入、首次连接信任或扫描。

审核要求：管理员才能为该端点设置临时挑战；在 WANIPConnection:2 的 `service` 内，`{urn:ipcamera:igd:create-only:1}createOnlyChallenge` 须返回本次 128 位随机值。固定控制端点须在处理 POST 时**原子**核对并消费 `IPCamera-<挑战>`，只分配空闲 TCP 端口、接受 60 秒有限租约或拒绝；不能重用、更新或覆盖既有映射，不得把请求降级为永久租约。此策略是额外的网关适配约定，**不是**标准 IGDv2 或普通描述 XML 能证明的属性；没有网关端策略便不支持。端点还须支持系统验证的 TLS 证书、带 Content-Length 的 ASCII XML；仅支持 IPv4、IGDv2 / WANIPConnection:2，不支持 v1、重定向、DNS 或代理。

两次确认后才访问描述，至多发送一次 `AddAnyPortMapping`，建议外部端口为 0。不会因开机、绑定、停服或超时自动创建、重发、续租或删除。**租期从网关处理时开始，不是从本机停服算起。路由器不受本应用控制**，不能保证到期、立即撤销或公网可达。超时或结果未知须手工在网关检查。公网 HTTP/RTSP 和凭据均是明文，建议 VPN。纯合成示例和配置见 `tests/igd_lease_test.cjs`（不打开任何系统 socket）。

## 页面与操作路径

- **首页**（`main.xml` → `Devices.ets`）：标题栏保留搜索和设置。主体是设备列表或居中的空态图，底栏进入本机服务；右下角橙色 `+` 展开 ONVIF、手动添加和扫码。点行播放，长按或点行内更多进入编辑/删除。未支持扫码的设备不启动扫描，浏览首页不申请相机或麦克风权限。
- **服务端**（`activity_server.xml` → `Index.ets`）：黑色预览占据整页，顶栏和底部连接信息叠在预览上；镜头、移动侦测、地址分享和客户端计数不再散落在首页表单中。服务控制和设置不会重新创建 `cameraPreview`，权限仍按需申请。
- **设置**（Android `preferences.xml`）：可从首页或服务页进入，使用深色偏好列表、橙色分类标题及二级配置。先显示云归档、录像格式/存储，再到移动侦测、观看端和服务端。只呈现有实际实现的选项；Harmony 的授权与安全提示不仿造 Android 专属开关。
- **观看端**（`activity_video.xml` / `activity_live_video.xml` → `Player.ets`）：画面为主体，轻点显示或隐藏控件。地址、认证及传输设置从菜单进入；声音、画中画和远端录像按当前播放能力显示，不因展示按钮而自动录音或发送。支持范围见 #52–56。
- **回放与管理列表**：`Playback.ets` 将本机文件选择、播放面和进度操作分层；`RemoteArchives.ets` 按 Android `ArchivePicker` 的“类别 → 文件”选择远端录像。ONVIF 发现、RTMP 地址管理使用深色列表和工具栏；浏览器 `/recordings` 仍是独立入口。
